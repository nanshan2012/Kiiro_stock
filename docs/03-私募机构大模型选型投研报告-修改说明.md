# 修改说明：私募机构大模型选型投研报告（复核与优化）

本说明记录对原始草稿（来源：指定 Google 文档）的复核结论与逐项优化，便于管理层快速核对"改了什么、为什么改、依据是什么"。

## 一、原稿评估（总体）

- **优点：** 结论方向正确、引用了厂商官方页面、对"M365/Excel 重度团队优先 Claude"的判断站得住脚。
- **主要问题：**
  1. **结构未对齐高管决策需求**：原稿按"Claude 产品线 → Claude vs ChatGPT → Claude vs Gemini"展开，缺少"结论先行 + 排序 + 合规警示"的采购报告骨架。
  2. **定价信息不完整**：仅给出 Claude 的详细定价，**完全缺失 ChatGPT 与 Gemini 的价格**，无法支撑"三选一"采购对比。
  3. **部分事实已过时或不全**：未反映 ChatGPT Business 年付降价与 Codex 座位拆分、未反映 Gemini 已并入 Workspace 套餐等近期变化；金融连接器清单不完整。
  4. **合规警示分散**：MNPI、权限隔离、数据留痕等关键风险散落在正文，未独立成段。

## 二、逐项修改与依据

### 1. 结构重组为三段式（按要求的输出结构）
- 改为：**① 选型结论与推荐排序（结论先行）→ ② 核心场景对比分析 → ③ 合规与部署警示**，并新增"按规模分档的试点配置建议"与"参考来源"。
- 语体改为平实、专业的商业报告体，减少排版装饰，仅在对比处使用简短列表（符合既定输出规范）。

### 2. 补全 ChatGPT 与 Gemini 定价（原稿缺口）
- **ChatGPT：** 新增 Plus 约 $20/月；Business 约 $25/席/月（月付），**年付近期由 $25 下调至约 $20/席**；自 **2026-04-02** 起拆分为"标准座位（固定月费）+ Codex 座位（按用量）"。Enterprise 联系销售。
  - 依据：OpenAI 商业定价页、OpenAI "Codex flexible pricing for teams"（明确提到将 Business 年付由 $25 降至 $20/席）。
- **Gemini：** 新增并强调**重大变化——Gemini 已并入 Google Workspace Business/Enterprise 套餐、不再单独加购收费**（此前约 $20–30/席加购）。补充 Workspace 价格参考（Business Starter≈$7、Enterprise Standard≈$23、Enterprise Plus≈$30），以及独立 Gemini Enterprise 联系销售。
  - 依据：Google Workspace 定价与帮助页、2026 年公开定价梳理（交叉验证）。

### 3. 校正/补全 Claude 定价表述
- 原稿仅给"年付"价。补充**月付与年付双口径**：Team Standard ≈ $25/席（月付）/ $20（年付）；Premium ≈ $125/席（月付）/ $100（年付）。
- 原稿称 Team"5–150 人"。**官方仅可确认 5 席起的最低门槛，150 上限未在官方页面得到确认**，故改为"最低 5 席起，规模更大转 Enterprise"，避免不实表述。
- 明确 Enterprise 为"座位费 + 用量（API 费率）"，座位费仅覆盖平台访问、Cowork/Claude Code 等高消耗场景 token 另计。
  - 依据：claude.com/pricing、support.claude.com 选择套餐页与 Enterprise 计费页、多源定价梳理交叉验证。

### 4. 更新并扩充金融数据连接器清单（贴 PE 工序）
- 原稿连接器：PitchBook、S&P Capital IQ、Morningstar、Daloopa + Aiera/Third Bridge、Chronograph、Egnyte、LSEG、Moody's。
- 经核实后**确认并扩充为**：PitchBook、S&P Capital IQ、**MSCI**、Morningstar、Chronograph、LSEG、Daloopa、**FactSet**、Third Bridge、**Dun & Bradstreet、Guidepoint、SS&C Intralinks**；**Moody's 以 MCP 应用接入（逾 6 亿主体）**。
- **保留但降权**了原稿中未在本轮检索复现的项（如 Aiera、Egnyte）——未否定其存在，但不作为重点主张，以坚持"事实至上"。
- 新增**对 PE 最对口的能力**：约 10 个金融智能体模板 + **PE 专用插件（deal sourcing、DD 清单、IC memo、组合公司 KPI 监控）**。
  - 依据：Anthropic finance-agents 公告、claude.com 金融插件教程、affinity.co 与公开报道交叉验证。

### 5. 校正 ChatGPT 金融能力的事实
- 将"2026-03-05 发布"改为更稳妥的"**2026 年 3 月初发布（beta，基于 GPT-5.4 Thinking）**"，并补充 **ChatGPT for Excel 同时支持 Excel 与 Google Sheets**（侧边栏原生）。
- 连接器中，**S&P Global、LSEG 已可明确核实**（MCP 应用/连接器）；FactSet、Dow Jones Factiva、Daloopa 沿用原稿表述但标注为"原始研究所列"，不夸大。
  - 依据：OpenAI ChatGPT for Excel 页与帮助文档、S&P Global / LSEG 官方页面。

### 6. 合规与部署警示独立成段并强化
- 新增独立章节，系统化覆盖：①个人版不可作合规工具；②企业级治理（SSO/SCIM、审计、合规 API、保留、IP allowlisting）优先于模型体验；③**MNPI 与信息隔离 / 权限感知检索**；④**数据驻留与监管留痕（SEC 17a-4 / FINRA / DORA）**；⑤第三方连接器是"能力 + 成本 + 合规"三重变量，需自有数据订阅；⑥产品更替快、建立季度复核机制。

### 7. 全文加入价格/功能时效性免责声明
- 报告开头与结尾、附录均强调：价格、座位类型、连接器随时变动，**签约前以厂商官网与销售报价为准**，并指定季度复核机制。这是对"事实至上"约束的工程化落实。

## 三、未决项 / 需机构自行向销售核实的事项

1. ChatGPT Enterprise、Gemini Enterprise 的**逐项合规条款**（数据驻留区域、不可篡改留存、DPA 细则）。
2. 各金融连接器**对应的数据订阅授权范围与费用**（AI 连接器不替代数据订阅）。
3. Claude Team 是否仍有"150 席"上限等**具体席位区间**。
4. Enterprise 按 token 用量计费下，**机构实际工作负载的成本估算**（Cowork/Codex 等高消耗场景）。
