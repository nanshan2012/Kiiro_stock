# 提示词 · 步骤 1:独立作答

> 用法:**分别**复制给 GPT 和 Gemini。此阶段**不要**让任一模型看到另一个的答案(防锚定)。

```text
请独立回答以下问题,不要假设另一个模型的观点,也不要迎合我。

问题:
[填入你的问题]

背景:
[补充业务背景、目标读者、已知约束]

请严格按以下结构输出:
1. 结论(一句话先给)
2. 核心依据(逐条)
3. 关键假设
4. 不确定 / 可能遗漏之处(至少 3 条)
5. 必须由外部核实的事实(并指明"该去核对什么、去哪核对")
6. 如果我错了,最可能错在哪
7. 自评置信度(0-10)

要求:
- 区分"事实 / 推理 / 判断 / 建议"。
- 证据不足时,请直接说"证据不足",不要硬凑。
- 不要堆砌结论,把推理过程讲清楚。
```

> 提示:自评置信度仅供参考——LLM 的"自信"常与正确率不符,真正的把关在步骤 4(外部验证)。
