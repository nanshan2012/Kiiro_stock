# 步骤 4:外部验证闸门(强制,非可选)

> 这是**决定真值**的一步。前面三步只是"组织讨论",真假对错要靠模型**之外**的依据来定。
> 核心心法:**走出模型,去对主源。** 多个模型一致,完全可能一起错。

## 按问题类型选择"预言机(oracle)"

| 问题类型 | 用什么判定真伪 |
|---|---|
| 事实 / 数据 / 时效信息 | 打开**主源**(官方文档、原始公告、一手数据)逐条核对 |
| 代码 | 实际**编译 / 运行 / 跑单元测试** |
| 数学 / 计算 | 用计算器 / 脚本 / 符号计算**重算** |
| 引用 / 文献 | 确认引用**真实存在** 且 **确实支持**该结论 |
| 无法核实 | **弃权(abstain)**,标为"未决",不要硬凑结论 |

## 引用核查清单(逐条打勾)

- [ ] 链接/出处**真的存在**(打得开,不是编的)。
- [ ] 来源是**一手/权威**来源,而非二手转述。
- [ ] 引用内容**确实支持**结论(而非被断章取义或张冠李戴)。
- [ ] 信息**仍然有效**(注意时效:版本、价格、政策、模型 ID 等极易过期)。
- [ ] 至少有一条**独立于模型**的证据(不是"另一个模型也这么说")。

## 一句话自检

> 如果我现在必须为这个结论负责,我手上**模型之外**的证据够不够?
> 不够 → 要么去补证据,要么**弃权**。
